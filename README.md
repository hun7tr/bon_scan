# Bon_Scan

Kassenbons mit dem iPhone fotografieren, offline auslesen und auswerten: was du gekauft hast, wie viel für welche Kategorie, wie viel davon vegan, vegetarisch, Fisch oder Fleisch war, wie viel Convenience und wie viel gesund.

**Installieren:** Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Beim ersten Start mit Internet wird die Texterkennung (etwa 10 MB) geladen und gespeichert, danach läuft alles ohne Netz. Alle Daten bleiben auf dem Gerät.
